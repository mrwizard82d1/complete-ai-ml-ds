What is Matplotlib?
- A python plotting library
- Allows us to turn our data in pretty visualizations
	- AKA, Figures

Matplotlib part of
- Data analysis
- Experiments
	- Presenting results?

Why?
- Built on NumPy arrays (and Python)
- Integrates directly with `pandas`
- Can create basic or advanced plots
- Simple to use interface
	- Once you "get it"

Steps
1. Create data
2. Create plot (figure)
	- An empty plot
3. Plot data (a figure)
	- Axes on the figure
4. Customize plot
	- Titles
	- Axis labels
	- etc.
5. Save / share plot
	- Used to shore work
