What types of database exist?
- Very complicated, broad, etc

Why are all necessary?
- Different databases are useful for different tasks

Major database types
- All perform the same essential function
	- Ensure that data exists beyond its creating application
- Relational
	- Organize data into "relations"
- NoSQL
	- Beginning in the 2000s
	- Needed to store data in
		- **Multiple data stores**
	- Allow us to parallelize work
		- Multiple machines
		- Store **distributed data**
- NewSQL
	- Try to combine
		- Relational and
		- NoSQL databases
- Function specific databases
	- Search
		- ElasticSearch
		- Solar (sic)
	- Computation
		- Apache Spark
