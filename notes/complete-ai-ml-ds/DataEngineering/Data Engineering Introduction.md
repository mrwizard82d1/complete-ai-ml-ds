We'll be covering a topic often forgotten
- Working as a 
	- Data Scientist or
	- Data Engineer

Data science is all about using data to make decisions
- Allows a computer to solve a problem that
	- Is too complicated for people
	- Is too tedious and too long for people

Definitions
- Machine learning is a technique
- Data science
	- Using data and converting it to something useful
		- For a product
		- Or a business
- Data analysis
	- A subset of data science
	- Allows us to analyze the data we have
- Data engineering
	- The "missing piece"

Data engineering
- Questions
	- Who brings all this data to us?
		- In a "nice" format
	- Where does this data come from?
	- How do we manage this data?
		- Do we simply "throw it out" when finished?
	- Who labeled this data?
- Ideally, the data is available to us in a reasonable format
- Who is this mythical figure
	- Takes all the incoming data for many different sources
	- And then produces it or maintains it
		- So that machine learning / data scientists can use it effectively
