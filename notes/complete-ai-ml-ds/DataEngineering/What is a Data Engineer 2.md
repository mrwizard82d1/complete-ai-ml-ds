Data engineers create data pipelines

Another example:
- Keiko Corp needs water
	- Requires rain
		- Similar to original data sources
	- Collect water into streams
	- Streams flow into lakes
	- A dam allows us to collect and transport water to cleaning facility
	- We then provide pipes from the water cleaning facility to endpoints
- A data engineer performs a similar process

A data engineer
- Ingests data from various sources
- Move all collected data into a data lake
	- A single location
- Must be managed
	- Perform data transformation
		- From one format to another
		- Into a data warehouse
- A data warehouse allows others to **use** our data
	- A location for structured, filtered data with a specific purpose

A data engineer
- Builds a pipeline
- To collect data from many sources into a data lake
- Extracts and formats data from the lake into a data warehouse
- To be used by the business
