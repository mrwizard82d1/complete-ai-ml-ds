Three main tasks of data engineers
- Build ETL pipeline
	- Extract - Transform - Load
	- Steps
		- Extract data
		- Transform it to useful form
		- Load into data storage

Second job
- Builds tools to monitor entire data pipeline

Third job
- Maintain
	- Data lakes
	- Data warehouses
- Ensure availability of resources to others

Tool landscape is **quickly changing**
- Beware
- Continue reading and researching
- But do not use until needed
