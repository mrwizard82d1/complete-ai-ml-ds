Data is valuable
- Some companies **sell data** to make money
- Other companies use data to improve their product
- Part of a product
- Enables answering questions
	- Are we doing ok?
	- Can we do better

Four different types of data
- Structured data
	- Typically easy to read
	- May be tabular
	- Perhaps relational databases
- Semi-structured data
	- Examples: XML, CSV, JSON
	- Consider Kaggle as a source of data sets
		- Enter "XML" in search bar will identify projects with .xml data
		- Click on "Filter" button
			- Can filter by types of files
			- For example, JSON
- Unstructured data
	- Examples: pdf, emails, documents
		- Understanding is difficult
- Binary data
	- Music, pictures, videos

Most business have **all** these kinds of data
- A data engineer will use and organize data in **all** these forms 
	- To make this data useful to the business
