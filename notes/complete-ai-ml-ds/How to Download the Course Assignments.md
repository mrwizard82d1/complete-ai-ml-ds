Suppose you want to access **one** notebook
- Click "Raw button"
- File > Save Page As 
	- Select folder for download
	- Leave filename unchanged

Open terminal to access notebooks
- Navigated to directory containing download
- See `pandas-exercises.ipynb.txt`
- Download
- Activate `conda` environment
- Execute `jupyter lab`
- Load the file if necessary

As an alternative, one can use Google Colab to "download" the file for use in the Colab environment
