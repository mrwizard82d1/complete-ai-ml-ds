Model of machine learning
- A typical program
	- Maps a set of inputs
	- To an output
	- We (programmers) tell the computer what to do
	- A computer is **very** fast
- In machine learning,
	- We supply the **input**
	- And the **output**
	- But ask the machine to figure out the function (transformation)
		- The machine writes the **function**
		- AKA, a **model**
		- AKA, an **algorithm**
		- AKA a "brain" that maps inputs to desired outputs
	- The created function is **very** complex
		- This process creates many issues

To have the computer create the function
- We must **train** the machine by
	- Giving it lots and lots of data
- We then **test** that the function gives 
	- The correct output
	- For the specified input

In summary, "machine learning"
- Is a computer
- Writing its own function
- Based on supplied inputs
- And expected outputs
