We previously walked through many ways to create `numpy` arrays

Options
- `np.random.randint()` - random integers
- `np.random.random()` - random floating point (real) numbers
- **Beware** - only **pseudorandom**

Random numbers generated by `numpy` appear to be random
- But what if we wanted to share our notebook with someone else?
- What if we wanted them to **exactly** reproduce the results that we saw - but on their system?
- `np.random.seed()` to the rescue!

Seeding the (global) Python random number generator
- Calling `np.random.seed(seed=2718)` 
	- **Determines** the sequence of random numbers generated after the call to `seed()`
- According to the documentation, this steps is **not** recommended
	- Instead, according to NEP19,
		- "The preferred best practice for getting reproducible pseudorandom numbers is to instantiate a generator object **with a seed** and pass it around."
		- Within a Jupyter notebook for distribution, set the seed **early** in the notebook.

```python
import numpy as np
rng = np.random.default_rng(2021)
rng.random(4)
```

See [this article](https://builtin.com/data-science/numpy-random-seed). Additionally, see [this article on setting the **seeds** for machine learning experiments](https://odsc.medium.com/properly-setting-the-random-seed-in-ml-experiments-not-as-simple-as-you-might-imagine-219969c84752) for a more robust process. Finally, read [this article on best practices](https://blog.scientific-python.org/numpy/numpy-rng/) for using `numpys` random number generators.

These articles suggest a **different** general approach.
- Optionally, generate a random seed
```python
import secrets

seed = secrets.randbits(128)
```
- The **copy and paste** this seed into the call to `np.random.default_rng()`
- Initialize a random number generator for the notebook **early**
	- `rng = np.random.default_rng(38414055920670544972848117448307182675)`
- Use `rng` whenever you need random numbers
- Note that `rng` can draw these random numbers from many, many distributions
	- See the help for `rng`
